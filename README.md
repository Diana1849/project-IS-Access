# Restaurant Management System (Microsoft Access)

A database project built with Microsoft Access to manage the daily operations of a restaurant.

## Tables
- CUSTOMERS: customer data
- EMPLOYEES: employee data (role, salary, contact info)
- MEALS: menu items with category and price
- ORDERS: customer orders and dates
- ORDERITEMS: meals and quantities in each order
- PAYMENTS: payment amount, date, and method

## Queries
- CustomerOrders: orders per customer
- TopSellingMeals: best-selling meals
- LeastPopularMeals: least ordered meals

## Forms
Data-entry forms for customers, order items, meals, and employees.

## How to use
Download project_is_final.accdb and open it with Microsoft Access 2010 or later.
